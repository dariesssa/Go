# Go
## Лабораторная работа: решение биквадратного уравнения на Go

### Цель работы
Изучить основы процедурного программирования на языке **Go (Golang)**, принципы строгой статической типизации, работу со стандартной библиотекой ввода-вывода, валидацию данных и обработку ошибок без использования объектно-ориентированных парадигм.

### Постановка задачи
Разработать консольное приложение на языке Go, осуществляющее поиск вещественных корней биквадратного уравнения:
\[Ax^4 + Bx^2 + C = 0\]

### Требования к реализации
1. **Управление проектом:** инициализация проекта как Go-модуля (`go mod init`).
2. **Ввод данных:**
   * Программа должна поддерживать передачу коэффициентов \(A\), \(B\) и \(C\) в качестве **аргументов командной строки** (`os.Args`).
   * В случае отсутствия аргументов или ошибок при их парсинге, программа должна автоматически переходить к **интерактивному ручному вводу** из консоли (`fmt.Scanln`).
3. **Валидация:**
   * Защита от ввода некорректных типов данных (буквы вместо чисел) с очисткой буфера ввода.
   * Проверка главного математического ограничения: коэффициент \(A \neq 0\). При ручном вводе программа должна циклически запрашивать корректное значение до тех пор, пока оно не будет введено.
4. **Математическая логика:**
   * Реализовать замену переменной \(t = x^2\) и решение квадратного уравнения \(At^2 + Bt + C = 0\).
   * Использовать функции пакета `math` (в частности, `math.Sqrt`) для извлечения корней.
   * Использовать конструкцию `switch` для ветвления логики разбора промежуточных корней \(t_1\) и \(t_2\).
   * Программа должна корректно обрабатывать случаи, когда уравнение имеет 4, 2, 1 или 0 вещественных корней.
